# The Tea Veranda – website (theteaveranda.co.uk)

Plain HTML/CSS/JS website. No build step needed.

## Put it on GitHub
1. Go to github.com → New repository → name it `theteaveranda` → Create.
2. Click "uploading an existing file" and drag ALL files and the `images` folder from this ZIP in. Commit.

## Publish on Netlify
1. app.netlify.com → Add new site → Import an existing project → GitHub → choose `theteaveranda`.
2. Leave build command empty, publish directory `.` → Deploy.
3. Site settings → Domain management → Add domain `theteaveranda.co.uk` and follow Netlify's DNS steps at your domain provider.

## Editing
- Text: open the `.html` files. Photos: replace files in `images/` keeping the same name.
- Enquiry forms (table, cake, events, vouchers) open a prepared email to clevedon@theteaveranda.com. No payment is taken online.
- VIP list: paste your Mailchimp signup link into the VIP form later to activate it.
